# VICE CITY LEGENDS 6

ملفات مشروع اللعبة بصيغة ويب قابلة للنشر كتطبيق ويب تقدمي (PWA).

## الملفات
- `index.html` — اللعبة وواجهة التحكم باللمس.
- `manifest.json` — اسم التطبيق وإعدادات التثبيت واتجاه الشاشة الأفقي.
- `sw.js` — تخزين الملفات الأساسية للعمل دون اتصال بعد أول تحميل ناجح.
- `icon.svg` — أيقونة التطبيق.

## النشر
ارفع الملفات الأربعة إلى جذر مستودع GitHub، ثم فعّل GitHub Pages من Settings → Pages واختر Deploy from a branch ثم `main` و`/(root)`. بعد نشر الموقع افتح رابط Pages عبر HTTPS على هاتف Android لإضافة اللعبة إلى الشاشة الرئيسية.

## ملاحظة حول APK/AAB
هذه الحزمة هي نسخة PWA وليست ملف APK أو AAB بحد ذاتها. إنشاء AAB يتطلب خطوة تغليف/بناء إضافية بعد نشر الموقع، ولا تضمن هذه الملفات وحدها قبول التطبيق في Google Play.
